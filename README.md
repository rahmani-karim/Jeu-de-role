# Jeu de Rôle Textuel en C

Ce projet académique est un jeu de rôle textuel développé en langage C. Il met en pratique des concepts d'algorithmique et de structuration de données.



## Fichiers inclus
* `main.c` : Point d'entrée du programme.
* `jeu.c` / `jeu.h` : Logique principale du jeu et définitions.
* `makefile` : Script de compilation.
* `Rapport_Projet algorithmique.pdf` : Rapport détaillant l'architecture logicielle et les algorithmes implémentés.
